# 要件・スコープ

## 初期マイルストーン（現時点の実装対象）

顔アバターUIの詳細仕様は [spec/face-avatar/README.md](../spec/face-avatar/README.md) にまとめている。
初期実装スコープは以下の一式（詳細は上記spec参照）。

- キャラクターの顔をLittleFS(フラッシュ)から読み込んだ画像アセットで表示し、複数の表情
  （neutral/happy/alert/sleep）を切り替える。
- IMU傾き・タッチ入力による瞳の視線トラッキング。
- 上部テレメトリヘッダー（システムステータス・バッテリー表示）。
- 下部3ボタン（電源・Wi-Fi・停止）。

## 将来拡張（今回のスコープ外・設計だけ阻害しないよう考慮）

- マイク入力（音声反応の口パクなど）によるさらなるインタラクティブ表現。
- WiFi等ネットワーク機能の本格統合（[既存コードの扱い](legacy-code.md) を参照）。

新機能を検討する際は、上記将来拡張を妨げない設計（表情状態や描画処理を疎結合に保つ）を意識すること。

関連ドキュメント: [アーキテクチャ](architecture.md) / [既存コードの扱い](legacy-code.md)
