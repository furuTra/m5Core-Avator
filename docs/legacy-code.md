# 既存コードの扱い

`src/main.cpp` には元々 WiFi スキャナーのデモ実装（スキャン結果表示・電源アイコンのタッチ判定など）が
残っている。この実装は削除せず、**参考実装として保持しつつ、顔表示機能を主目的とする構成へ段階的に
再構築する**方針とする。

- 顔表示に無関係なロジック（WiFiスキャン等）を新規モジュールに混在させない。
- 将来 WiFi 機能を復活・統合する場合は、独立したモジュール（例: `lib/WifiScanner/`）に切り出す。
- `M5.Touch` によるタッチ判定や `M5.Power.powerOff()` など、Core2 の操作パターンは既存コードの実装を
  参考にしてよい。
