# プロジェクト概要

- **目的**: M5Stack Core2 の画面にキャラクターの顔（表情）を表示する。
- **対象ハードウェア**: M5Stack Core2（ESP32、320x240 IPS液晶、タッチパネル、SDスロット搭載）。
- **フレームワーク**: Arduino framework + PlatformIO。
- **主要ライブラリ**: `m5stack/M5Unified`（M5GFX を含む。ディスプレイ・タッチ・電源制御などを統一APIで扱う）。

関連ドキュメント: [要件・スコープ](requirements.md) / [アーキテクチャ](architecture.md)
